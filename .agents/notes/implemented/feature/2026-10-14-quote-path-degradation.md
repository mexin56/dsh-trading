# Agent Note: 报价路径不可用时的降级派生（Ticker 契约允许同源序列派生）

Status: implemented

## Problem

2026-10-14，东财把本机出口的**报价快照路径**掐了：`push2/api/qt/ulist.np/get`（以及此前就已失效的
`stock/get`）一律空回——TCP/TLS 通、服务端收到请求即断；换 UA / 去掉 Referer / 加 `ut`/`cb` / 换
`82.push2`、`push2delay` 别名都无效。同刻同机的 `push2his`（kline、trends2）、`searchapi`、
`datacenter-web`、`quote.eastmoney.com` 网页全部 200。表现是自选栏**整栏价格变 `—`**、行名停在
代码上（名字只在快照到达时回填），而迷你走势照画（那条走 push2his）——同一份数据、一半可用。

更根本的一层：免密公共源的报价路径被限频或直接回收是**常态而非事故**（同一天内两条路径相继失效，
2026-09-08 还有 push2his 整 IP 断开的记录）。侧栏的取价能力不该整体押在单一端点上。

## Decision

**契约（`@dshtrading/api` 的 `Ticker` 文档）**：允许连接器在首选取价路径不可用时用**同源序列**派生
快照。派生值必须自洽（涨跌幅由同一对 `price`/`prevClose` 推出，名称与昨收取自同一响应）；**拿不到的
量宁可缺省**（`volume` 本就可选），不得用窗口合计之类近似值冒充当日累计；降级**不得掩盖**「该标的
确实不存在」——`TRADING_SYMBOL_NOT_FOUND` / `TRADING_UNSUPPORTED_SYMBOL` 照实上报。消费方无需区分
快照来自直取还是派生。

**实现（connector-eastmoney，cn/hk 两实例）**：

- 派生源 = 同源的 `trends2?ndays=1`（push2his）。末根分钟 bar 的收盘价即最新价——2026-10-14 实测
  与同刻腾讯报价**逐位一致**；`data` 顶层自带 `name`/`preClose`/`decimal`，故名称与昨收不必再取
  第二个端点。该响应的价格是**十进制值**，不适用报价端点那套 `×10^f1` 整数口径。
- **不给 `volume`**：窗口第 6 列之和在 cn 恰等于当日累计（196239 = 196239），hk 却低于当日累计
  （18,418,300 vs 19,933,548，缺 16:00 后收市竞价）——近似值冒充准确值不如缺省。
- 触发边界：只有 `TRADING_NETWORK` / `TRADING_UPSTREAM_ERROR` 才降级；not-found / unsupported 原样
  上抛。派生自身失败抛回**原始**错误，绝不吞成 not-found、也不交出一条空快照。
- `getTicker` 与 `getTickers` 都有这条兜底：批量失败时对请求表里的每个 secid 逐只派生，转不成 secid
  的符号仍跳过；一只都派生不出来时仍抛原始错误（空表在契约里是「一个都没收录」，与「整批失败」不是
  一回事）。
- **降级态自身有界**：派生快照按 secid 做 60s TTL 缓存，且**只在降级分支读写**——报价路径恢复即返回
  直取的新鲜值，绝不用陈旧派生值顶替。没有这道闸门，降级态就是每 8s 一拍 × N 只，又一次把仅存的那条
  路打穿。

## Alternatives considered

- **客户端兜底**（快照缺失时用走势序列末根收盘价当最新价）：改动更小、任何数据源都受益，但「序列→
  价格」要由每个消费方各自实现一遍，且行情舞台、Agent 工具等消费方拿不到（它们不画走势）。放连接器里
  做一次，所有消费方同等受益。
- **只用日 K 派生**（`kline/get?klt=101`）：单请求更小、当日成交量准确，但没有名称（自选行名字回填
  就断了），且日 K 的「当日收盘」盘中是否实时更新依赖上游行为，不如分钟序列明确。
- **同时打 trends2 + kline**（价格/昨收/名称 + 准确成交量）：降级态请求数翻倍，换一个侧栏不显示、
  契约里本就可选的字段——否决。
- **不做降级**：保留「整栏 `—`」，把可用性继续押在单一免密路径上；今天已证明这条路径会整条消失。
- **给派生值打标让消费方区分**：消费方要为此各加一档渲染与判断，而派生与直取的价格语义同一（都是
  「最新可得的价格」），只差滞后——不给消费方添负担，改为在契约里写明滞后口径。

## Consequences

- 东财报价路径再被掐时，自选栏从「整栏 `—`」降为「价格滞后最多一根分钟 bar」（盘后即当日收盘价），
  名称/昨收/涨跌幅照常。实测：报价路径空回时 12 份派生快照全部拿到，cn 与腾讯逐位一致，hk 用
  `r_hk` wire 对照亦 Δ=0。
- 降级态请求量有上界：60s 内同一 secid 最多一次 trends2（探针实测：换写法重取、批量重取、跨方法重取
  均为 0 次）。
- 其它连接器不受影响（可选行为，当前只有 eastmoney 实现），未实现的市场行为逐字节不变。
- 证据：spikes/impl-eastmoney-quote-endpoint/（p3 探针 + EVIDENCE 的「附2」节，含一次 wire 用错的
  订正）；用例见该包 getTicker/getTickers 的降级用例组。
- 本机出口经 fake-IP 代理（`198.18.0.0/15`）会偶发空回：探针对照源取不到时打 `SKIP` 而不是 FAIL，
  但连接器侧的断言不放宽（拿不到派生快照仍判 FAIL）。
